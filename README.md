# 防静音防震动 RingerGuard

一个极简 Android 小工具。

功能只有一个：

> 手机一旦进入静音或震动模式，就自动切回响铃模式。

## 功能说明

本 App 只处理 Android 的铃声模式：

- 响铃
- 震动
- 静音

如果检测到手机变成：

- 静音
- 震动

就自动切回：

- 响铃

## 不会做什么

本 App 不会修改任何音量：

- 不修改铃声音量
- 不修改媒体音量
- 不修改通知音量
- 不修改闹钟音量

本 App 也不会：

- 不联网
- 不定位
- 不读取通讯录
- 不读取通话记录
- 不监听电话
- 不录音
- 不使用传感器
- 不定时轮询
- 不频繁唤醒手机

## 工作原理

App 开启后会启动一个前台服务。

前台服务不是把 App 界面一直显示在屏幕上。

它只是让系统知道：

> 这个 App 有一个后台守护服务正在运行。

App 会监听 Android 系统的声音模式变化事件：

```java
AudioManager.RINGER_MODE_CHANGED_ACTION
